# アイデアを投稿する（ワークショップ主催者向けガイド）

ワークショップやブレストで出たアイデアを、「ブレストアイデア・オープンデータセット」に投稿していただけませんか。

集まったアイデアは、生成AIが発想のヒントとして使えるオープンデータとして公開されます。あなたのワークショップで生まれた突拍子もないアイデアが、どこかの誰かの次のアイデアのタネになります。

**用意するのは「テーマ」と「アイデア」の一覧だけです。** カテゴリ分けや形式の整理は、メンテナーが行います。

## 投稿できる人

ワークショップの**主催者またはファシリテーター**の方なら、どなたでも投稿できます。分野や地域は問いません。

## 投稿できるアイデア

- ワークショップで**参加者（人間）が出したアイデア**に限ります。
- 生成AIが出した案は投稿できません。AIを使ってよいのは、付箋の文字起こしなどの**補助だけ**です。
- アイデアの良し悪しは問いません。実現できそうにない案、突飛な案こそ歓迎です。

## 投稿までの流れ

```
① ワークショップの前：参加者にデータ公開のことを伝え、同意をもらう
   ↓
② ワークショップ：付箋などにアイデアを出す
   ↓
③ 後日：「テーマ」と「アイデア」の一覧を作る
   ↓
④ 投稿フォームから送る
   ↓
⑤ メンテナーが確認して公開（目安：1か月以内）
```

### ① 参加者の同意をもらう

アイデアの公開には、それを出した参加者の同意が必要です。ワークショップの始めに、次のように伝えてください。

> 今日出たアイデアは、「ブレストアイデア・オープンデータセット」として、誰でも自由に使えるオープンデータ（CC0）で公開する予定です。生成AIがアイデアを考えるときのヒントなどに使われます。
>
> - 公開するのはアイデアの文章だけで、皆さんのお名前は記録しません。
> - 一度公開すると、すでに出回ったコピーまでは取り消せません。
> - 公開してほしくないアイデアがあれば、その付箋に×印を付けるか、終わったあとに教えてください。

同意は口頭でもかまいませんが、記録を残しておくと安心です。

**未成年の参加者がいる場合**は、保護者の同意、または学校・主催団体としての同意を得てください。

### ② ワークショップ中のコツ

- **付箋1枚に1アイデア**を書いてもらうと、あとで一覧にしやすくなります。
- 付箋に名前を書かないよう、最初に伝えておきます。
- 終わったら、付箋を貼ったボードを写真に撮っておきます。
- 公開しない付箋（×印など）は、一覧に入れないでください。

### ③ 一覧を作る

テンプレートに、テーマとアイデアを書き込みます。

- [template.xlsx](template.xlsx)（Excel・Googleスプレッドシート用）
- [template.csv](template.csv)（CSV）

| theme | idea |
|---|---|
| 坂の多いまちで高齢者の買い物をどう楽にするか | 坂の上と下でロープウェイ式に荷物だけ運ぶ |
| | 買い物代行を中学生の職業体験にする |
| | 坂の途中にベンチ付きの「休憩商店」をつくる |

書き方のポイントは次のとおりです。

- **1行に1アイデア**。付箋1枚が1行です。
- **テーマ**は、ワークショップで掲げた問いを、そのままの言葉で書きます。同じテーマが続く場合は、2行目からは空欄でもかまいません。
- **アイデア**は、付箋に書かれたとおりに写します。言い換えたり、まとめたりしないでください。話し言葉や方言もそのままで大丈夫です。
- 1つのファイルに、複数のテーマが入っていてもかまいません。
- 個人名、メールアドレス、電話番号などは書かないでください。

**一覧を作るのが大変なときは、生成AIに文字起こしを手伝ってもらえます。** 付箋の写真をClaudeなどに渡して、次のように頼んでください。

> 添付した付箋の写真に書かれているアイデアを、付箋1枚につき1行で文字起こしして、「theme」と「idea」の2列のCSVにしてください。テーマは「（ここにテーマ）」です。
> 文字は書かれているとおりに写し、言い換え・要約・追加は絶対にしないでください。読めない文字は［?］としてください。×印の付いた付箋は除いてください。個人名が書かれていたら、その行を教えてください。

AIの文字起こしには間違いが混じることがあります。投稿する前に、写真と見比べて確認してください。

### ④ 投稿フォームから送る

**投稿フォーム：https://forms.gle/Rc63KSZfZMcJ9xyy7**

ファイルを添付するか、フォームにテーマとアイデアを貼り付けて送ります。ファイルを添付する場合は、Googleアカウントへのログインが必要です。

### ⑤ 確認と公開

メンテナーが内容を確認して、データセットに追加します。

- **アイデアの良し悪しで選ぶことはありません。** 除外するのは、個人情報を含むもの、重複、アイデアではない行（見出しやメモ）など、形式上の理由があるものだけです。
- 明らかな誤字の修正や、個人名を外すといった最小限の手直しをすることがあります。
- カテゴリ分けはメンテナーが行います。
- 公開されると、[データセット](../data/)に追加されます。

## 削除・修正をお願いしたいとき

公開後に「このアイデアを消してほしい」「文字起こしが間違っていた」という場合は、投稿フォームの備考欄、またはこのリポジトリのIssueでお知らせください。テーマとアイデアの文言を教えていただければ対応します。

参加者ご本人からの削除依頼にも対応します。ただし、CC0で公開したデータは、すでに出回ったコピーまでは取り消せません。

## よくある質問

**Q. 付箋の数が少なくても投稿できますか？**
A. 1件からでも大歓迎です。

**Q. 以前に開催したワークショップのアイデアも投稿できますか？**
A. 参加者の同意が取れているものなら投稿できます。同意が確認できない場合は、投稿を控えてください。

**Q. 会社の研修で出たアイデアを投稿してもいいですか？**
A. 社外に出してよい内容かどうか、所属先に確認してから投稿してください。公開は取り消せません。

**Q. 同じアイデアがすでにデータにあったら？**
A. テーマが同じで文言も完全に同じ場合は追加しません。それ以外は、似ていても別のアイデアとして追加します。

**Q. 投稿したら、自分の名前は出ますか？**
A. 出ません。フォームのお名前と連絡先は、確認のご連絡にだけ使います。
