# データセット：ブレストアイデア

ながさきキャンバスで行ったブレインストーミングの結果を、生成AIなどから再利用しやすい形にまとめたデータセットです。
「アイデアを否定しない」ブレストの精神に沿って、アイデアの良し悪しによる選別は行っていません。

## ファイル

| ファイル | 内容 |
|---|---|
| `brainstorm_ideas.json` | データ本体（JSON配列、UTF-8） |

URLから直接取得できます。

```
https://raw.githubusercontent.com/foot737/brainstorm-ideas/main/data/brainstorm_ideas.json
```

## スキーマ

| 項目 | 内容 |
|---|---|
| `theme` | ブレストのテーマ |
| `theme_category` | テーマの分類（アーバンデータチャレンジの作品テーマ10分類に準拠） |
| `idea` | アイデア本文 |
| `origin` | アイデアの出どころ。`human`（人間が出した案）または `ai-assisted`（AIと一緒に出した案） |
| `license` | ライセンス（`CC0`） |

```json
{
  "theme": "長崎バスを盛り上げるアイデア",
  "theme_category": "道路・交通",
  "idea": "降りますボタンが無いバスを運行：バス停で待っている人がいるバス停でしか止まらない。駆け引きを楽しむ。",
  "origin": "human",
  "license": "CC0"
}
```

## 収録内容

12テーマ、450件のアイデアを収録しています。

## 作成方法

1. ブレストのまとめ資料（PDF）からアイデアを抽出しました。
2. 見出しと説明があるカード形式のアイデアは、「見出し：説明」の形で1件にまとめています。
3. 同じ付箋が資料内の複数ページに再掲されている場合は、1件に統合しています。
4. 1行に複数のアイデアが並んでいる場合は、別々のアイデアに分割しています。
5. カテゴリ図、まとめ、キーメッセージ、編集部のピックアップなど、アイデアの再掲や要約にあたる部分は除外しています。
6. 個人名は収録していません。明らかな誤字のみ修正しています。
7. データの公開については、ながさきキャンバスの主催者から同意を得ています。

## 注意事項

- アイデアはすべて人間がブレストで出したものですが、一部の資料はブレスト後にAIスライドツールで要約・清書されています。そのため、文章表現にはAIによる要約が含まれます。
- アイデアは実現可能性や正確性を検証したものではありません。発想のきっかけとしてご利用ください。
