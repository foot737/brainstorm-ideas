# データセット：ブレストアイデア

ながさきキャンバスで行ったブレインストーミングの結果をもとに、各地のワークショップから投稿されたアイデアを加えて、生成AIなどから再利用しやすい形にまとめたデータセットです。
「アイデアを否定しない」ブレストの精神に沿って、アイデアの良し悪しによる選別は行っていません。

## ファイル

| ファイル | 内容 |
|---|---|
| `brainstorm_ideas.json` | データ本体（JSON配列、UTF-8） |

URLから直接取得できます。

```
https://raw.githubusercontent.com/foot737/brainstorm-ideas/main/data/brainstorm_ideas.json
```

## スキーマ

| 項目 | 内容 |
|---|---|
| `theme` | ブレストのテーマ |
| `theme_category` | テーマの分類（アーバンデータチャレンジの作品テーマ10分類に準拠） |
| `idea` | アイデア本文 |
| `origin` | アイデアの出どころ。`human`（ワークショップで人間が出した案）。収録するのは人間が出したアイデアだけです |
| `license` | ライセンス（`CC0`） |

```json
{
  "theme": "長崎バスを盛り上げるアイデア",
  "theme_category": "道路・交通",
  "idea": "降りますボタンが無いバスを運行：バス停で待っている人がいるバス停でしか止まらない。駆け引きを楽しむ。",
  "origin": "human",
  "license": "CC0"
}
```

## 収録内容

最初の公開時点（2026年11月）で、12テーマ・450件のアイデアを収録しています。以降は、投稿を受け付けるたびに追加されます。

## 作成方法

1. ブレストのまとめ資料（PDF）からアイデアを抽出しました。
2. 見出しと説明があるカード形式のアイデアは、「見出し：説明」の形で1件にまとめています。
3. 同じ付箋が資料内の複数ページに再掲されている場合は、1件に統合しています。
4. 1行に複数のアイデアが並んでいる場合は、別々のアイデアに分割しています。
5. カテゴリ図、まとめ、キーメッセージ、編集部のピックアップなど、アイデアの再掲や要約にあたる部分は除外しています。
6. 個人名は収録していません。明らかな誤字のみ修正しています。
7. データの公開については、ながさきキャンバスの主催者から同意を得ています。

### 投稿の取り込み

最初の公開以降は、ワークショップの主催者からの投稿を、次の方針で取り込んでいます（[投稿ガイド](../contribute/README.md)）。

- 投稿できるのはワークショップの主催者で、参加者からCC0公開の同意を得たものに限ります。
- 収録するのは人間が出したアイデアだけです。AIは文字起こしの補助にのみ使用できます。
- アイデアの良し悪しによる選別はしません。除外するのは、個人情報を含むもの、重複（同じテーマで完全に同じ文言）、アイデアではない行（見出しやメモ）、AIへの指示文などです。
- 編集は、明らかな誤字の修正、個人名の削除、1行に複数の案がある場合の分割に限ります。言い換えや要約はしません。
- どの投稿から追加されたかは、データの項目ではなく、リポジトリのコミット履歴に記録しています。
- 削除の依頼があった場合は、テーマとアイデアの文言が一致する行を削除します。

## 注意事項

- アイデアはすべて人間がブレストで出したものです。ただし、最初の公開時のデータの一部は、主催者がブレスト後にAIスライドツールで清書した資料から作成しているため、文章表現にAIによる要約が含まれます。
- アイデアは実現可能性や正確性を検証したものではありません。発想のきっかけとしてご利用ください。
