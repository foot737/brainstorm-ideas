# brainstorm-ideas

**人間がブレストで出したアイデアを、生成AIの発想の材料に。**

長崎のコミュニティ「ながさきキャンバス」で行ったブレインストーミングの結果をオープンデータにしたものです。あわせて、そのデータを生成AIから使うためのスキルを公開しています。

ブレストの良さは、アイデアを否定しないことから、突拍子もない案や、誰かの案に乗っかった思いがけない案が生まれることです。一方、生成AIは「もっともらしい平均的な答え」に寄りがちです。人間の評価前の生のアイデアをAIに混ぜることで、AIとのアイデア出しをもっと面白くすることを目指しています。

アーバンデータチャレンジへの応募作品として、Code for Nagasakiのメンバーが作成しました。

## 中身

| フォルダ | 内容 |
|---|---|
| [`data/`](data/) | ブレストアイデアのデータセット（12テーマ・450件） |
| [`skill/nagasaki-brainstorm-ideas/`](skill/nagasaki-brainstorm-ideas/) | データをヒントに生成AIが一緒にブレストするスキル |
| [`contribute/`](contribute/) | ワークショップのアイデアを投稿するためのガイドとテンプレート |

## データを使う

データはJSON配列で、次のURLから直接取得できます。サーバーは不要で、読み取り専用のAPIとして使えます。

```
https://raw.githubusercontent.com/foot737/brainstorm-ideas/main/data/brainstorm_ideas.json
```

```json
{
  "theme": "長崎バスを盛り上げるアイデア",
  "theme_category": "道路・交通",
  "idea": "降りますボタンが無いバスを運行：バス停で待っている人がいるバス停でしか止まらない。駆け引きを楽しむ。",
  "origin": "human",
  "license": "CC0"
}
```

項目の説明や作成方法は [`data/README.md`](data/README.md) を参照してください。

## スキルを使う

テーマを伝えると、AIがデータセットから3種類のヒントを取り出します。

- **乗っかり**：テーマに近いアイデア
- **掛け合わせ**：別々のテーマのアイデアを2つ組にしたもの
- **偶然の出会い**：テーマとは無関係なアイデア

そのうえで、「否定しない」ブレストのルールに沿ってアイデアを10件ほど出します。どの案にも、ヒントにした人間のアイデアが引用されます。

使い方は3通りあります。

1. **Claudeに追加する（SKILL.mdだけ）**：[`SKILL.md`](skill/nagasaki-brainstorm-ideas/SKILL.md) をスキルとして追加します。スクリプトとデータは、使うときにこのリポジトリから自動で取得します。
2. **Claudeに追加する（オフライン版）**：[Releases](../../releases) からzipをダウンロードして、スキルとして取り込みます。データとスクリプトが同梱されています。
3. **その他の生成AI**：SKILL.mdとデータのJSONファイルを添付して、「この手順でブレストして」と頼みます。

スクリプトは単体でも使えます（Python 3、標準ライブラリのみ）。

```bash
python3 skill/nagasaki-brainstorm-ideas/scripts/pick_ideas.py "商店街を盛り上げたい 商店 街 にぎわい"
python3 skill/nagasaki-brainstorm-ideas/scripts/pick_ideas.py --list-themes
```

## アイデアを投稿する

ワークショップやブレストを主催した方は、参加者が出したアイデアを投稿できます。用意するのは「テーマ」と「アイデア」の一覧だけです。カテゴリ分けなどの仕上げは、メンテナーが行います。

- 投稿できるのは、ワークショップで**人間が出したアイデア**だけです（AIで生成した案は対象外）。
- アイデアの良し悪しで選ぶことはありません。

詳しくは [投稿ガイド](contribute/README.md) をご覧ください。

## 出力例（「商店街を盛り上げたい」）

> **乗っかり**
> 1. **子ども店長の日**：月に1日、商店街の各店を子どもが店長として仕切る。店主は「先生」役として横で見守る。
>    ヒント：「地域の商店主を「先生」として招いた特別授業」（子どもたちが学びながら成長するための地域連携アイデア）
>
> **掛け合わせ**
> 2. **店主の青春スピーチ大会**：高校生のスピーチ大会のノリで、店主が「この店を始めた日」を3分で語る。
>    ヒント：「話題性と集客：「長崎でしかできないこと」で400人が応募するような話題性のある企画を作る。」×「高校生による青春スピーチ」
>
> **偶然の出会い**
> 3. **買い物バランスナビ**：いつも同じ店にしか行かない人に、「今週はまだ八百屋に行っていません」と教えてくれる買い物アプリ。
>    ヒント：「バランスナビゲーション：得意・苦手科目の偏りを防ぎ、最適な学習比率へ誘導」（学習記録アプリ機能改善提案）
